\# 🛩️ Animated Journey of a Fighter Jet



A computer graphics animation project built using \*\*C/C++\*\* and \*\*OpenGL (GLUT)\*\*. This project demonstrates core computer graphics concepts—including object drawing, translation, and scene transitions—through the animated flight of a fighter jet across multiple environments.



\*\*🎓 Academic Context\*\*

Developed as a project for the Computer Graphics course at \*\*American International University-Bangladesh (AIUB)\*\*, under the guidance of \*\*Noboranjan Dey\*\*, Lecturer, AIUB.



\*\*👥 Team Members\*\*

Developed collaboratively by \*\*Md. Jakaria Naim\*\* \*(Me — Developed the Rural Landscape / Village Scene)\*, Tofayel Hossain, Tanvir Hosen Nishat, and Md. Abdul Malek Sobuj.



\*\*🚀 Project Overview\*\*

The animation follows a sequential storyline, taking the viewer through three distinct scenes. First, a fighter jet departs from its home airbase and ascends into the sky. Next, the jet flies over a detailed urban environment featuring the AIUB campus. Finally, the scene transitions to a peaceful village, contrasting the urban flight path. \*(The village scene was entirely designed and developed by Md. Jakaria Naim).\* 



This project is intended for students, educators, or anyone interested in learning practical implementations of computer graphics.



\*\*🛠️ Technology Stack \& Future Enhancements\*\*

The system is built on \*\*C/C++\*\* utilizing the \*\*OpenGL\*\* graphics API and \*\*GLUT\*\* (OpenGL Utility Toolkit). Future plans for this project include integrating background audio and sound effects, adding interactive keyboard and mouse user controls, and incorporating more intricate environmental details with dynamic weather effects.
